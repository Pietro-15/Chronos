# CHRONOS

## **CHRONOS** is a quick, light diary app for taking notes on your daily activities.

This app tracks your daily routines and activities and stores them as memories you can look back on later. It serves as a modern diary you can access anywhere from your phone.

An upcoming feature is **Duo Goal**, where you and a friend keep a shared diary of each other's activities. Each of you can rate and comment on the other's entries. A streak feature is planned too.

Chronos is still in early development. It is built with React Native, Expo and TypeScript, which I am learning from the very basics.

- Track and save your daily goals, achievements and activities.
- A digital diary you can access anywhere, anytime.
- Duo Goal: a collaborative diary for you and a friend.
